Fujifilm X-T1 XPan Mask

A small patch to the X-T1's firmware that switches its "HD Framing" 16:9 guidelines into a 65:24 panoramic mask in the viewfinder and on the LCD screen.

Experimental. Use at your own risk.

  • This changes your camera's firmware. It has only been tested on my one X-T1 so far (which was running the latest v5.52 firmware)
  • A failed or interrupted update could leave the camera unusable, and it may not be repairable
  • It is provided as-is, with no warranty and no support
  • This is an independent hobby project. It is not affiliated with or endorsed by Fujifilm

What it does

The "HD framing" option under Screen Set-Up → Framing Guideline → HD Framing is switched from 16:9 to 65:24 (and is set to a full mask, rather than just being thin lines). No cropping occurs however, images (JPEG and RAW) are left untouched, and the chosen aspect ratio is not changed (it's best to ensure that 3:2 is selected, with "L" JPEGs).

You'll want to crop the output images yourself when importing from the SD card.

Try it

Make sure you have Python 3 installed on your system.

  1. Download the official X-T1 firmware 5.52 (FWUP0005.DAT) from Fujifilm
  2. Download the patch kit and unzip it next to that file: Download the patch kit zip · 4 KB
  3. Run the patcher (it'll refuse to write anything unless your file is the 5.52 file): 
    python3 patch_dat.py FWUP0005.DAT out/FWUP0005.DAT xpan-mask.patch
  4. Copy out/FWUP0005.DAT to the root of a freshly formatted SD card
  5. Make sure your battery is fully charged, set Screen Set-Up → Framing Guideline → Grid 9, and set Image Size → L 3:2
  6. Update the camera the way Fujifilm's own firmware instructions describe (eg. holding DISP / BACK and powering it on)
  7. Set the Screen Set-Up → Framing Guideline → HD Framing guideline, you should now see the "XPan" crop in your viewfinder and LCD screen

Undo it

Flash the unmodified official FWUP0005.DAT the same way (you might want to keep a copy of it somewhere safe).

Cropping your photos

The camera still saves full 3:2 files. For an exact 65:24 frame, crop the 4896×3264 image to 4896×1808.
